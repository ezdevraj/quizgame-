# 🎯 Quiz Game Website

A responsive, interactive web-based quiz game where users can test their knowledge across various topics, get instant feedback, and view their final scores.

---

## 🚀 Features

* **Interactive Quiz Interface:** Multiple-choice questions with real-time feedback.
* **Score Tracking:** Displays score percentage and summary at the end.
* **Responsive Design:** Styled cleanly using HTML, CSS, and JavaScript for mobile and desktop screens.
* **Timer Feature (Optional):** Time limit for answering questions.

---

## 🛠️ Tech Stack

* **HTML5** - Structure and layout
* **CSS3** - Styling, animations, and responsive layout
* **JavaScript (ES6+)** - Game logic and dynamic DOM manipulation
